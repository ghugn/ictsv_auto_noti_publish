TỰ ĐỘNG LẤY TOKEN (KHÔNG CẦN CHẠY CODE)

Bấm nút để mở trình duyệt, đăng nhập là hệ thống tự lấy token 100%!

Cách nhanh nhất (Khuyên dùng)

Bấm nút bên dưới, một cửa sổ Chrome/Edge sẽ mở ra. Bạn chỉ cần đăng nhập tài khoản trường, hệ thống sẽ tự động bắt Token và lưu ngay mà bạn không cần phải copy hay gõ bất kỳ dòng code nào!

Hoặc làm theo cách thủ công:
1
Mở trang Đặt vé Bách Khoa:

Vào trang ctsv.hust.edu.vn/dat-ve và đăng nhập tài khoản của bạn.

2
Bấm F12 -> tab Console, dán đoạn mã này rồi ấn Enter:

Giải đáp: Tại sao trên máy tính bị lỗi không đặt được mà điện thoại lại được?

Qua phân tích trực tiếp mã nguồn Frontend của trang ctsv.hust.edu.vn/#/dat-ve:

  • 1. Cơ chế xác thực Office 365 (ADAL/OIDC): Chức năng đặt vé gọi API riêng bknexus/Event/Register và yêu cầu phiên Microsoft Office 365 còn hiệu lực. Trên trình duyệt máy tính, các chính sách bảo mật chặn cookie bên thứ ba (Third-party cookie) hoặc iframe làm mới token của Microsoft thường xuyên gây ra lỗi 401 (Phiên đăng nhập không hợp lệ) hoặc popup đăng nhập bị chặn.
  • 2. Trên điện thoại (App iCTSV): Ứng dụng di động lưu trữ token xác thực trong bộ nhớ an toàn (Secure Storage) và gắn trực tiếp vào header/body mà không phụ thuộc vào cơ chế cookie iframe của trình duyệt web máy tính.
  • 3. Quá tải giao diện khi mở vé: Trên web máy tính, khi hàng ngàn sinh viên cùng F5, giao diện Element-UI của trang web thường bị đơ, không mở được Modal đăng ký. Ứng dụng này giải quyết triệt để vấn đề đó bằng cách gửi trực tiếp POST request tới API máy chủ trong vòng vài chục mili-giây, bỏ qua hoàn toàn giao diện web!
